# 蛋糕顶面中心与吸盘工具中心标定

这两个脚本独立于比赛主程序。机器人上已部署到 `/home/spark/c_calibration/`。

## 1. 图像顶面中心

相机和机械臂驱动启动后，先把机械臂移到避让相机的位置，再拍无遮挡图像。对目前这张图：

```bash
python3 /home/spark/c_calibration/cake_corners.py \
  --image /tmp/cake_clear.png --hint 335 265 --roi 220 160 230 230 \
  --plane-z -50 --output /tmp/cake_top_auto.png
```

自动四角只是候选。**移动机械臂前必须看标注图并确认四点是顶面真实边角**。若边缘因印花、遮挡、地面纹理导致自动结果不准，在 VNC 终端使用 `--manual`，按顶面四角点击，按 Enter 接受；或者用 `--points u1 v1 ... u4 v4` 输入确认后的四点。

本次人工核对图像 `/tmp/cake_clear.png` 的四角约为 `(282,216)`、`(389,215)`、`(392,315)`、`(281,316)`；对角线交点是 `(335.98,264.58)` 像素。以当前程序假定的地面金砖顶面 `z=-50 mm` 投影，橙色标记参考系的暂估位置是 `(202.24,2.65) mm`。**这不是吸盘口中心**。

## 2. 手动微调吸盘

在机器人终端：

```bash
source /home/spark/spark_noetic/devel/setup.bash
python3 -u /home/spark/c_calibration/arm_jog.py \
  --center-x 202.24 --center-y 2.65 \
  --log /home/spark/c_calibration/measurements.csv
```

脚本启动时只读取 `/SwiftproState_topic` 的实际位置并关闭气泵。命令：

- `approach`：分段到地面金砖顶面上方约 35 mm，不接触。
- `step 1`、`step 2`、`step 5`、`step 10`：设定单次步长，单位 mm。
- `x+`、`x-`、`y+`、`y-`、`z+`、`z-`：单轴移动一次，并显示目标和实际反馈坐标。
- `where`：查看当前反馈；`watch`：连续显示 5 秒。
- `home`：先升高，再退回 `(130,0,35)`；`quit`：结束程序，**不自动移动**。

默认最低 `z=-35 mm`。若现场确认吸盘口仍有足够间隙，可先输入 `quit`（不会移动），用 `--min-z -45` 重启脚本，再以 1–2 mm 步进下降并重新测量间隙。脚本允许的绝对下限是 `-50 mm`，但**不应仅凭命令坐标推断已经接触**；每次降低下限前必须根据现场实测间隙判断。不要把手伸入工作区时发移动命令。

脚本只允许保守范围内的小步调节，泵始终关闭。`approach` 的高度基于地面金砖顶面 `z=-50 mm` 的假设；没有实测砖顶高度之前，不要继续下降到接触。必须由现场人员从侧面看吸盘口，而不是看橙色标签，记录偏离顶面中心的方向和距离。收臂前确认手已离开工作区。

记录三个以上不同位置的“砖顶中心像素、暂估机械臂坐标、实际对准吸盘时的反馈坐标”，才能判断吸盘偏移是否可以用固定值补偿。二层蛋糕应单独验证高度。
